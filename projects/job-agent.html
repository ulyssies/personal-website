Job Match Agent

A daily job-search agent that scores listings against my resume and sends a ranked morning report.

Node.js Claude AI Adzuna API Nodemailer HTML/CSS
Personal tool · Active

01 — Why I built this

Job searching manually is exhausting: the same listings appear across boards, most do not match my actual skills, and there is no easy way to filter for genuinely entry-level roles. I built an agent that does the daily search for me, scores every listing against my resume using AI, and delivers a ranked report to my inbox each morning.

02 — How it works

01
Parse
Claude extracts skills and profile details from my resume.
02
Fetch
Listings come from Adzuna, The Muse, and Jobicy across target cities.
03
Score
Every job gets a 0-100% score for skill alignment and seniority fit.
04
Save
Results are written to a rolling 30-day run history.
05
Deliver
A dark-mode dashboard and ranked email report are generated each run.
ARCHITECTURE

Resume parsing, multi-source job fetch, AI scoring, daily delivery

03 — What was hard

  • Dual-resume routingI am applying to both Data Analyst and Software Engineering roles, which use different resumes. The agent routes each job to the right resume by title so scores compare against the relevant skill set.
  • Seniority fit as its own signalA job can match my skills and still require five years of experience. Separating entry-level fit from skill alignment let me filter for reachable roles without lowering the overall quality bar.
  • Prompt caching to control API costsThe resume gets cached across scoring batches in a single run. That means I only pay to send it once, keeping a run of roughly 200 jobs around forty cents.
